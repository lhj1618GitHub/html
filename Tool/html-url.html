工作原理

  1. 输入 GitHub 令牌。
  2. 选择一个 HTML 文件。
  3. PageDrop 创建一个公开仓库，并将其上传为 index.html。
  4. GitHub 构建 Pages，直链地址会显示在这里。
⌁

令牌保留在本地

本工具没有后端服务器。令牌仅存在于发布期间的浏览器标签页中，不会写入仓库或 URL。

为了最大程度的安全，建议创建一个专用的细粒度令牌，并在发布后撤销它（如果您不打算重复使用本工具）。
